# Automotive Performance Analytics Pipeline

A Python and Pandas data processing pipeline designed to clean, transform, and evaluate vehicle datasets, extracting key performance metrics such as power-to-weight ratios and statistical comparisons across models.

---

### Features
* **Data Cleaning & Preprocessing:** Handles missing values, standardizes units, and removes dataset anomalies.
* **Metric Calculation:** Derives key automotive figures including power-to-weight ratio, engine displacement efficiency, and segment benchmarking.
* **Exploratory Analysis:** Aggregates multi-variable statistics across manufacturers, engine classes, and drivetrain configurations.

---

### Tech Stack
* **Language:** Python 3.11+
* **Libraries:** Pandas, NumPy
